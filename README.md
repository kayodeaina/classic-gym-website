# Classic Gym Website

A responsive gym website developed as part of my BSc (Hons) Software Development studies. The project demonstrates front-end web development using Angular, TypeScript, HTML5, and CSS3.

## Project Overview

The Classic Gym Website provides a modern single-page interface for presenting gym services, fitness information, and related content. The project focuses on responsive design, structured components, and a user-friendly web interface.

## Key Features

- Responsive web design
- Single-page application structure
- Gym services and fitness information
- Reusable Angular components
- User-friendly navigation
- Mobile-friendly interface

## Technologies

- Angular
- TypeScript
- HTML5
- CSS3
- Responsive Design
- Single-Page Application (SPA)

## Purpose

The project demonstrates the application of front-end software development techniques to create a responsive and structured website for a gym and fitness environment.
